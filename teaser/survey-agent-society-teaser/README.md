## 为什么收这张图

以一座共同活动的虚拟城市场景承载任务规划、协作和工具使用，再用三个局部场景与对话气泡解释含义；这是本批最接近叙事型 teaser 的一张。

原论文 Figure 1，用具体场景描绘作者设想的 Agent 社会；属于愿景概念图，不是已验证的系统能力展示。

## 可以借鉴

- 先给一个能被迅速理解的主场景，再用局部放大区讲不同能力。
- 气泡与短标签围绕人物行为，减少抽象术语堆积。
- 城市场景和人物主要是原有位图，文字、标注框与部分形状才是可编辑对象；保留第三方视觉素材权利。
