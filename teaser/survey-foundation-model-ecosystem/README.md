## 为什么收这张图

用五个连续色带串起数据产生、整理、训练、适配与部署，并在两端放人、在中间放多路数据与模型，提示讨论模型影响时应同时看到上下游生态。

CRFM 综合报告中的社会技术生态概念图，原文 Figure 3；关注数据和参与者关系，适合讨论综述范围及影响边界。

## 可以借鉴

- 阶段色带建立阅读顺序，跨阶段箭头表达多条路径。
- 把参与者放在流程两端，避免只画模型模块而遗漏数据和使用者。
- 图中的图标主要是作者原有嵌入位图，阶段标题和部分结构保留矢量对象。
