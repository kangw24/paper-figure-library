## 为什么收这张图

用同一输入将两种方法的三维外观和深度排在两侧，中央小图直接补充速度与参数量，使定性效果和成本在同一个版式中对齐。

质量与效率结合的结果型 teaser。

## 可以借鉴

- 相同输入作为对照的视觉中心
- 质量、几何与效率分层表达
- 少量小图支撑主要视觉结论
