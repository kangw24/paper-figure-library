## 为什么收这张图

将 Profile、Memory、Planning、Action 并列成四列，列内再分子能力，顶部说明共享的 LLM 基础，适合综述比较多个系统的共同组成。

综述统一框架图；表达组件分类与共同基础，不把并列栏目误读为从左到右执行的流水线。

## 可以借鉴

- 固定列宽与重复的标题层级，便于并列扫描。
- 用浅色区分组件，列内只保留短语。
- 顶部共享来源与四列能力分解分开，不额外制造串行箭头。
