# 紧凑排版、层级与视觉风格

## 将模糊反馈定位到实际对象

“AI 味”“太 plain”“很散”不是自动套滤镜的指令。先对照原图指出：哪些大容器、哪些颜色、哪些线、哪片空白、哪些重复内容造成问题。风格判断不证明作品来源。

本用户多轮反馈中稳定出现的问题：圆角阴影多彩卡片；浅底加同色描边的矩形；粗体下灰线；灰色小字；大安全区；长空箭头；相同模板反复用；无意义口号和统计数；局部公式与图元分离。

同时用户明确接受装饰、色彩、机制展开和必要底纹。因此不能反向写成“禁用所有背景/矩形/颜色”的规则。

## 密度的对象是信息关系

密度不足时先检查三项：

1. **组织是否松散**：把一个机制的图、公式、标签合回相邻位置，减少跨区寻找。
2. **科学对象是否不足**：是否只写了名词，没有实际场、特征、采样、通量、局部对照？补有意义的机制对象。
3. **面积是否错配**：辅助目标占整列，复杂实现挤在底部，标题占一行大空间，箭头占几百像素却没有中间步骤。

不要用缩小所有字体、加高画布、重复场图、堆满文字来通过“更密集”。在同一展示尺寸比较前后稿。没有通用填充率或固定子图数量指标。

## 按关系选择不同版式

| 科学关系 | 版式候选 | 重点 |
|---|---|---|
| 同一对象的不同范式 | 共享起点，分支并列，对齐输出 | 复用坐标与视觉变量便于比较 |
| 领域分类与交叉 | 分组矩阵、交叉轴、局部图簇 | 区分正交维度，避免伪互斥分类 |
| 一个方程的多种表述 | 共用问题定义，多区局部推导 | 保持问题条件一致，公式贴对应对象 |
| 总体到实现 | 紧凑总览 + 较大局部展开 | 引线表示层级，不误读为串联 |
| 困难与处理机制 | 按现象配对局部解法 | 子图面积按机制复杂度分配 |
| 构造与诊断 | 构造主体 + 邻接诊断阵列 | 共用状态，局部损失就地解释 |

不要为了变化而强行圆环、斜排或放射构图。关系不适合时，整齐的横竖仍然正确；二维来自层级和交叉关系，不来自弯折数量。

## 先排内容，再补连线

1. 固定画幅与预计阅读尺寸；标题、图例、色标都计入面积。
2. 放主场图和最长的实际 TeX 公式，不用大概字数估宽。
3. 按语义邻接安排局部对象，先解决主次面积。
4. 确定输入/输出/参数端口，再画连接。
5. 补标签与必要装饰，检查空白是否是分组间隔还是无意义走廊。

每个区域先用不可见边界做预算；布局预算框不应自动成为成图容器。

## 箭头与线条

- 用最短清楚路径，优先直线或少量整齐折线。弯曲确实能减少交叉时才用。
- 箭头终点落到正确对象或端口，避免指着整个卡片边缘而意义不明。
- 展开、对齐、放大用相应引线；数据流、参数更新、可选项有可解释区别。
- 箭头头部与线宽协调；不能线条粗到压过科学对象，也不能放映时消失。
- 删除重复边框、标题下横线和无意义分隔；不要误删域边界、网格、坐标轴、误差线、控制体边缘。
- 控制更新回线的长度。若必须绕整图，先重排相关模块，别只把线弯得更复杂。

## 底纹与装饰的条件用法

需要区分相关子图时，可使用连续、低干扰的区域底色；避免默认再加轮廓、阴影和圆角包裹。相邻底纹的交叠、颜色碰撞和接缝也要检查。用户后来要求 04/08 用底纹分组，不应被更早的去卡片要求一概禁止。

矩形域、张量、特征矩阵、采样网格有科学含义，可以使用矩形；问题是将每种内容放进重复 UI 容器。

优先增加解释机制的视觉细节：

- 同一场的截线、剖面、局部放大、边界内外标记；
- 网格线、实际求积点、采样位置、测试函数支撑域；
- 法向/切向、控制体、通量方向和守恒比较；
- 特征向量对齐、张量维度、单频率通道矩阵；
- 奇异位置、尺度放大、边界层网格、可解释的等值线。

每个新增对象回答一个问题。泛用大脑/芯片图标、装饰公式、随机点、无证据曲线不能替代科学细节。其他插画风格可以借鉴真实参考，但不能承担伪造证据的作用。

## 文字与内容层级

本用户要求科学图内英文，题注在图外；交流文字及中文汇报标题可以中文。

正常正文保持足够对比和可读字号，不把重要内容放成一排灰色细小字。标题、对象标签、坐标/图例有层级，但不让标题消耗主体面积。

不主动添加：One PDE · four formulations 这类重复口号；已经由图清楚展示的总结句；不参与比较的 12 observations / 95 sites 等醒目数目；左下角每页重复的 takeaway。

必要术语、单位、坐标、条件要留。完整图题、来源、长说明、复现参数放题注/备注。

## 04 与 08 的局部排版经验

04：上部只讲一次实例/算子与训练关系。DeepONet/FNO 作为较大的两个实现展开，共享上层算子；离散接口用短小对照条，不要大半页空长箭头。FNO 的整网、单层、单频率各自新增一层信息，不重画三遍 FFT。

08：构造主体与几何靠近；下部检查形成紧凑阵列，每项含科学对象和就地公式。总目标只占小区域，不能独占整列形成公式墙。采样来源与残差查询区接近，控制体放大有清楚定位。图内不靠样本数量填空。

## 检查是否真正完成

同时看完整图、局部放大、实际放映大小。用修改前后的相同尺寸比较，确认：主体更明确；相关对象更近；新对象提供新信息；没有裁切/碰撞；其他已认可颜色和数据没被改变。

风格微调不能只改生成器里一个函数就宣布完成；还要检查所有实例、旧 SVG 片段、缓存预览与最终导出。
