## 为什么收这张图

沿蛇形路线组织数据集年代，每张卡片复用名称、年份、模态图标和样例图四层信息；时间顺序、视觉差异和模态范围可以一起阅读。

综述中的数据与基准发展概览，原文 Figure 3；作为综述背景全景的构图参考，具体数据集性能不由此图比较。

## 可以借鉴

- 折返路线减少横向宽度，同时让卡片保持统一尺寸。
- 年份与模态放在卡片顶部，代表样例与名称放在下方，信息顺序稳定。
- 保留转弯处的阅读方向；数据集覆盖以作者所选版本为准。
