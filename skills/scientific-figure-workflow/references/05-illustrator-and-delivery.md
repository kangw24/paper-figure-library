# Illustrator 落地与文件交付

## 先保护可恢复状态

保留作者原件、用户已批准稿和本次工作副本。记录本次变更范围：文字、线条、布局、科学数据、场图映射分别列明。不要用完整重生成意外改变锁定对象。

多图任务维护清单：每图对应 SVG/PDF、预览、TeX、题注、原生 AI、核验状态。版本名表达先后和状态即可，不把空壳文件叫 final。

## 编辑器和文件格式各自能证明什么

- SVG 可含文本、路径、引用、滤镜和位图；有路径不代表整图完全矢量。
- PDF 可保留文字/矢量，也可能只有整页位图；能在 AI 打开不等于保持原分组结构。
- 公式转轮廓后可移动/编辑形状，但不能直接改文字。
- PNG/JPEG 可用于预览和放映，不是矢量可编辑源。
- 原生 `.ai` 应由 Illustrator 实际保存；不能把 PDF/SVG 改扩展名当作原生 AI。

交付按对象说明可编辑范围，避免一句“全可编辑”掩盖场图位图和轮廓文字。

## 导入前检查

1. SVG 有明确尺寸、正确 viewBox 和完整引用；检查外链图像、字体、clipPath、mask、use 与 marker。
2. 图内中文、题注、旧标题或隐藏残留符合当前要求；隐藏对象可能需要保留编辑用途，不能未经判断全部删除。
3. 图层/组按科学对象组织；避免把全图合成一个路径，也不强迫每个点一个顶级图层。
4. TeX 公式、颜色映射、孔洞透明区、裁剪与外部图片已有浏览器/渲染器基准图。

## 原生导入与保存

使用用户指定且可用的 Illustrator 控制方式。打开工作副本，适配画板，逐图检查；保存原生 AI，并按需要启用 PDF 兼容和压缩。再打开保存件，至少核查重要局部。

本案例 Illustrator 2023 导入某些 `marker-end` 产生箭杆缺失/方向问题，兼容副本将简单三角 marker 展开为显式路径，保留原箭杆。它是特定导入问题的修复，不是所有 SVG 的必做转换。

不能把只处理绝对 M/L 折线和简单三角形的脚本推广到任意 Bézier、相对命令、markerUnits、viewBox 和变换；复杂箭头须使用支持相应语义的转换器或在应用中展开，并逐项核验方向和比例。

遇到缺失链接、Tiny SVG clipping 等警告，判断受影响对象并比较渲染；不能仅关闭警告就声称无问题，也不能未经检查把整图宣布损坏。

## UI 控制失败时

先确认目标应用、窗口和可访问状态，再作有限重试。若用户已经切前台并展开，仍连续出现 `noWindowsAvailable`，不要循环要求用户执行相同步骤。

本案例能读菜单、用键盘打开/保存，但画布点击失败。采用的后续路径是明确披露“SVG 局部修改 → Illustrator 导入与检查 → 原生保存”，并非假称已手动调整所有锚点。

遵循工具自身限制，不用未授权 shell/脚本绕过 UI 操作要求。若另一可用路径在用户授权内，继续完成；确实需要用户输入时说明具体阻碍、已尝试内容和最小动作。

## 交付检查

- 全套图数量/编号完整，不能只交最近修改的 04/08。
- 预览和源件对应同一版本，哈希/文件大小用于追踪而非证明视觉无误。
- 箭头方向、公式边界、孔洞、遮罩、色标、图例、标签与字体实际检查。
- 原生打开/保存/重开证据优于扩展名；PDF-compatible AI 中的私有数据标记只能作为辅助证据。
- 打包后检查成员路径与可解压性；题注、TeX、源数据或计算代码按实际存在情况提供。
- 限制如实记录：桌面未实测、文字轮廓化、位图场、旧链接等；不要列与当前文件无关的假设警告。

最小交付可含：完整预览、指定源件、外置题注、必要复现资产、简短编辑范围说明。不是每次修一条线都必须再做大量文档。

## SVG 结构预检

```bash
python scripts/audit_svg.py path/to/figure.svg
python scripts/audit_svg.py path/to/figures --recursive --output audit.json
```

脚本使用 Python 标准库，只读取 SVG；若指定 `--output`，仅写该 JSON 报告。报告尺寸、元素计数、文字/CJK、位图嵌入、外部引用、悬空片段引用、重复 ID、marker、CSS 与滤镜等注意项。

非零退出码表示解析/结构错误、没有找到 SVG、或报告写入失败。外部依赖和兼容性提示本身不令退出码失败，因为它们有时是合法设计；仍须人工判断。

限制：不访问网络、不展开外部资源、不解析完整 CSS 级联、不计算路径视觉边界，也不判定颜色是否科学、排版是否紧凑、文本是否可读、是否存在图形越界。不能以“脚本通过”代替渲染、Illustrator 实测和科学审查。遇到复杂/不可信 XML 声明时拒绝处理而非加载外部实体。
