# 配色、字体与数学排版

## 先分清用户在改哪类颜色

| 系统 | 用途 | 修改时需保持 |
|---|---|---|
| 分类色 | 方法、分支、对象角色 | 同一语义一致、不同角色可区分 |
| 连续场色图 | 温度、解、系数、残差等数值 | 数据、单位、范围、归一化和色标对应 |
| 结构/背景 | 文字、轴、引线、分区 | 对比、层级、低干扰 |

“卡片太多彩”不授权替换场图色图；“网格太 AI”也不意味着去掉网格和采样点的有效颜色。案例中真正被指向的是浅底与描边捆绑，而不是颜色本身。

建立颜色语义表，记录用途、对象、色值或 colormap、归一化范围、是否锁定。已批准场图只在明确要求或发现科学误导时改动，改动须说明理由并展示影响。

## 从学术规范中能推出什么

Nature 的 figure guide 强调紧凑清楚的分面、高对比文字、易读字体、可访问颜色与可编辑文件；其示例包含 Okabe–Ito 色组。它不是要求所有科研图使用同一套“Nature 配色”。[Nature：Building and exporting figure panels](https://research-figure-guide.nature.com/figures/building-and-exporting-figure-panels/)

其中可用的分类色示例为：`#000000`、`#E69F00`、`#56B4E9`、`#009E73`、`#F0E442`、`#0072B2`、`#D55E00`、`#CC79A7`。按实际类别选少量，不是八种全部铺满。浅黄在白底上的小线/小字仍需单独检查。色组选择不能替代语义、背景与尺寸检查。

连续数据应选择适合数据结构、感知变化和色觉可访问性的色图；Crameri 的 Scientific colour maps 提供相应色图和诊断资料。[Scientific colour maps](https://www.fabiocrameri.ch/colourmaps/)

执行时区分：有序幅值用顺序映射；有意义的中心值/正负差异可用发散映射；周期量才考虑循环映射。不是所有残差都取绝对值，也不是所有发散图都应独立自动拉伸范围。

以上来源在本 skill 编写时核对于 2026-11-03；投稿时重新检查目标期刊当前规范。不要把配色包的 NPG 名称当作 Nature 官方认证，也不要声称已读未成功获取的论文全文。

## 可执行颜色检查

1. 比较图是否共用适当色标；不同物理量可以有不同色标，必须明确。
2. 判断颜色是否夸大本来平滑的结构，或掩盖零点、符号和异常值。
3. 查看色觉差异模拟；必要时用点型、线型、文字补充，不能只靠红绿区别。
4. 在实际大小检查细线和小标记；灰度检查是补充，不要求所有类别仅用灰度即可完全分开。
5. 文本对比度检查不等于分类色可辨识性检查；网页文字对比指标不能直接证明科学图所有颜色合格。

若仅修改分类色，比较前后场图文件哈希或像素，检查其归一化与色标未被顺手重生成。若用户明确要求改场图，则有意识地更新数据映射和所有对应图例。

## 字体

以干净、稳定的正文和数学字体建立层级；不要用一层层灰色小字让信息消失。局部语义色可用于匹配对象，但不必把所有标题涂成不同颜色。

按实际阅读尺寸确定字号。期刊印刷的点数不能直接当作 PPT 推荐字号；两者显示尺度和阅读距离不同。正文、变量、刻度的视觉大小需比较实际字形，不只比较 font-size。

## TeX 数学流程

1. 保存每条公式的 TeX 源和语义 ID，建立图中对象对应关系。
2. 用当前可用 TeX/数学渲染管线生成矢量或高质量兼容资产；不是手动拼 Unicode 上下标、分数字符和大括号。
3. 测量真实边界与基线后排版；检查积分上下限、括号、粗体向量、算子正体、变量斜体与间距。
4. 统一 apparent size：数学字形与旁边英文的 x-height、笔画粗细协调，不能仅把所有公式缩到相同外框高度。
5. 保持公式和解释对象相邻；长推导在题注/补充材料，图内保留理解关系必要的式子。
6. 实际检查导出与 Illustrator 导入后的缺字、裁切、基线、透明背景和链接资源。

保留 `.tex`、生成配置和资产映射，修改科学符号时更新源，不只手改轮廓。

### 可编辑文字与轮廓公式是不同交付

本项目为 Illustrator 兼容使用过公式轮廓 SVG。这能保留字形，但不能声称公式仍是可编辑文字。Nature 指南倾向保留可编辑文字及嵌入字体，因此投稿母版与演示兼容副本可能需要分开制作。不能把轮廓化通称为“符合 Nature 的最佳做法”。

### 本用户的中文 LaTeX 特例

仅当创建或修改**中文 LaTeX 文档**时，遵循其持久配置：使用原有 Codex 内置编辑器及 `compile_latex_document`，修改已打开文档时原地编辑，不切外部编译器。`fontset=none`，中文 TrueType 字体：

```tex
\setCJKmainfont{gbsn00lp.ttf}[AutoFakeBold=2,ItalicFont=gkai00mp.ttf]
\setCJKsansfont{gbsn00lp.ttf}[AutoFakeBold=2,ItalicFont=gkai00mp.ttf]
\setCJKmonofont{gbsn00lp.ttf}[AutoFakeBold=2,ItalicFont=gkai00mp.ttf]
```

西文和数学保持默认，不用中文字体覆盖 mainfont/sansfont。该用户曾遇到 Fandol OTF 编译成功但内置预览中文空白，不再切回；这不是所有预览器的通用结论。编译成功后实际检查中文显示，不能仅凭退出码声称修复。

这项配置不要求英文科学图插入中文，也不意味着所有独立数学资产都必须采用中文文档工作流。
