## 文件说明

- 作者原件保持源码归档中的字节不变，逐项记录归档 SHA256、成员路径和原件 SHA256。
- PDF 含真实矢量对象，但照片、插画和部分图标仍是嵌入位图；SVG 为转换件，文字转轮廓，不能称为作者原生 SVG。
- LightMem 两张图已核对固定版本源码及作者 GitHub 的图形文件清单，只取得 PNG，未制作 SVG 外壳。
- 非首图的应用、机制或任务总览均在条目里保留原图号，不以 Figure 1 编号决定分类。
- 同论文图、原四张参考图与现有元素通过各自 README 和 relationships.json 互链。现有元素是功能关联，不冒称从这些新图拆出。
