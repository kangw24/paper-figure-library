## 内容与构图

文本、激活和参数记忆采用同一医疗例子，三栏之间以不同路径说明编码、解码、缓存、微调和参数解码，上下长箭头概括巩固与激活方向。

三个记忆形态并列，局部双向连接及上下两条总体路径。

概念、方法差异或能力的总览，按主要表达用途归入 Teaser。
