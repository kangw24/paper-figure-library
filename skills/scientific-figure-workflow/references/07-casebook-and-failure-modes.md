# 过程复盘：失败、修正与适用边界

这是一次从找模板到六幅 AI4PDE 科研图、原生 Illustrator 文件和八页汇报草稿的过程总结。保留决策因果，不复制聊天记录。旧提案不代表最终方案；数字、软件版本与例子均不是下一任务的默认参数。

## 阶段 1：先把“找图”做对

最初混淆了 CS/AI 与会议名称，也把网络结构模板当作用户要的所有主图。用户进一步指出 Figure 1 风格更偏 teaser；SVG 可以接受，但希望真实范例和可复用源件。

后来建立私有图形库时出现两类问题：把 teaser 当成任何首图；用 agent 自绘的十几个符号充作抓取元素。修正方向是收真实作者文件、已有图标库和从真实原图提取的部件，分别标明来源、许可与可编辑程度。

仓库最终按用途分到根目录 teaser、architecture、element，以 Markdown 串联。会议/Oral/综述成为标签，不另造并列主目录。这一组织方式保留了范例与元素间的来源关系。

**迁移经验**：用户要求搜集时交付来源资产，用户要求原创制图时才制作作品；两者身份不混淆。

## 阶段 2：从泛用首图转向具体参考

用户逐步要求子图丰富的综述，并指向《Artificial intelligence for partial differential equations in computational mechanics: A review》的 Fig.1/2。这给出了当前审美和表达参照，而不是永久库规。

真正需要的是从例图中理解领域地图、范式对照、机制展开的组织，不是把“综述”写在文件夹名上，也不是只报搜索了多少网站。

**迁移经验**：实际看图并记录借鉴位置；把当前偏好与全局维护规则分开。

## 阶段 3：纲要到六图，最初方案为何失败

从 AI4PDE 思维导图选择 01、02、03、04、05、08。早期草案倾向大安全区、规则容器、灰色解释小字和水平/竖直流水线，题注甚至放进画布。

这些处理把研究关系拆成了 presentation 卡片：空间看似整齐，科学对象稀少；各图同版式，区别只在文字；所谓二维只是箭头弯折。

修正应同时发生在内容与布局：题注移外、英文进图、关系有层级、相关子图靠拢、按内容换版式、箭头表达操作而非装饰。不能靠多加颜色掩盖组织问题。

**迁移经验**：内容契约、空间预算和实际草图一起交付。用户要求改图后，不再只交新的规划网页。

## 阶段 4：多轮美术调整中的错误归因

| 反馈 | 当时容易做错的反应 | 应执行的修正 |
|---|---|---|
| 视觉失衡、填得不满 | 加一堆标签或把每格背景填色 | 查面积错配；补真正机制对象、局部对照 |
| 太 plain，要装饰 | 添加随机点、通用芯片、无意义曲线 | 补剖面、法向、支撑域、边界放大等解释性细节 |
| AI 味重 | 全部改黑白、细灰线 | 定位具体容器/描边/阴影与重复风格 |
| 粗体下灰线没删干净 | 只改一个标题 helper | 检索并检查所有实例与导出缓存 |
| 字体和公式难看 | 手调 Unicode 上下标 | TeX 排版，测量实际字形和基线 |
| 配色不科学 | 套所谓 Nature 色板覆盖全图 | 分开分类色与连续场色图，查来源和语义 |
| 网格、采样点太 AI | 删除所有颜色 | 去除多余底纹+描边组合，保留有效编码 |
| 二维排版 | 画长斜箭头、回折箭头 | 用分支、嵌套、并列与局部展开组织 |

“One PDE · four formulations”等口号重复了已经表达的事实，并未增加信息。12 observations、95 sites 等数字是本例设置，不是图的研究发现。不能把 setup 参数视觉化为结果亮点。

**迁移经验**：小修正保持作用域；调整线条不顺手换场图颜色，调整配色不重新生成实验数据。

## 阶段 5：科学机制复审不是删到安全

后续复审指出的问题涉及：分类维度混淆、变分条件缺失、连续与离散混同、参考与预测身份不清、输入目标错连、奇异性混称、软惩罚被误读为硬保证。

用户明确反对收窄。正确处理是保留原研究范围并修复条件、对象和联系；复杂内容通过多层展开组织，而不是默默删除。

最终六图的可核查条件见 [科学审查案例](02-content-and-science.md)。科学核查应回到原始方程、数据和计算；美术 agent 无法凭画面漂亮证明理论正确。

**迁移经验**：科学审查与美术审查可分工，但须围绕同一版本、同一数据身份；冲突由主 agent 解决并落实。

## 阶段 6：04/08 的密度问题为何反复出现

04 原本把大面积给了宏观比较，DeepONet/FNO 被挤在下部；底部离散箭头很长但信息少。修订中又一度出现“训练讲两遍”“每个展开都再画一套网络”的重复。

有效的组织是：一次说明实例/算子、训练与复用；较大区域展开两个实现；DeepONet 明确输入采样与特征内积；FNO 分清整网、单层与单频率；离散接口缩成短对照。各层新增关系，不重复算法。

08 原本右侧空、总目标独占长列，构造只有几个场与符号。有效的组织是：同一试探场的基线、边界因子、修正、合成靠近；采样与其真实来源靠近；四项诊断就地配公式，总目标收成小区域。

增加内容前先计算同一固定状态的诊断，不能为了四个子图就画四组虚构训练结果。后续允许底纹区分相关区域，但仍需修正相邻 c/d 底纹冲突；“允许底纹”不等于恢复彩色描边卡片。

**迁移经验**：不以画布变高或字号变小消化内容。长箭头和独立公式墙经常是组织未完成的信号，但需针对具体图判断。

## 阶段 7：Illustrator 与工具现实

用户要求开始 Illustrator 工作后，范围包括全部六图，不能只记住正在打磨的 04/08。

应用菜单和键盘可用但画布点击失败；用户切前台展开后仍报无窗口。继续反复请求同一动作没有价值。最终采用公开说明的 SVG 小修、原生导入检查与保存路径，未把它描述成逐锚点人工编辑。

原生导入暴露 marker 兼容、裁剪与链接等问题；这些需要实际检查，不能以浏览器 SVG 正常推断 Illustrator 正常。保留工作副本和公式源，核验原生保存、重开以及六图清单。

**迁移经验**：工具限制要影响执行路径和交付说明，不应变成无限重试或虚报完成。

## 阶段 8：从图到五分钟中期汇报

用户先要求参考一份 PDF，把放图内容做成八页；后来明确整个汇报只有五分钟，图解约 1.5–2 分钟。应保留完整草稿用于审阅，同时规划正文与备用，不让背景图挤占真实研究结果。

进一步反馈集中在左下角重复总结。将这些句子放到讲者备注，页面保留标题和科学图。不能每页又补一个结论条来“统一设计”。

**迁移经验**：论文图密度、投影可读性和口头时间是三个约束；拆图按语义，不按等宽裁切；用户删除的装饰内容要进入修订记录。

## 下次启动时的自查

1. 用户此刻要找参考、规划、改图、原生制作还是 PPT？交付是否对应动作？
2. 哪份是最新批准稿？哪些对象必须锁定？
3. 每个新增子图和箭头增加了什么科学关系？
4. 参考解、固定示例和实验结果是否区分？
5. 所谓密度提高是否其实只是缩字、加框或多写一句话？
6. 是否无意间把分类色修改扩展到了连续场？
7. 是否漏掉其他图、公式末行、色标或题注外置？
8. 文件是否真的能打开，且编辑范围说明准确？

这些是故障定位线索，不要求每次把八条检查向用户念一遍。最终反馈应围绕实际改了什么、如何核验、文件在哪里。
