Given the RGB-D observation of the environment and a language instruction, LLMs generate code, which interacts with VLMs, to produce a sequence of 3D affordance maps and constraint maps (collectively referred to as value maps) grounded in the observation space of the robot \textbf{(a)}. The composed value maps then serve as objective functions for motion planners to synthesize trajectories for robot manipulation \textbf{(b)}. The entire process does not involve any additional training.}
