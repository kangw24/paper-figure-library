## 为什么收这张图

从中心领域向两侧展开原理、方法方向、应用、比较与研究方向，颜色对应一层主题，形成清晰的综述阅读地图。

原论文 Figure 1 是综述组织路线图。此条作为综述分类总览参考收录，强调内容范围；不把普通分类树一概称作概念 teaser。

## 可以借鉴

- 先把综述范围划成少量一级主题，再让左右两侧分担长文本。
- 一级主题使用色块，叶节点只保留短标签，控制视觉层级。
- 章节编号由原论文 LaTeX 叠加；可编辑母图保持原字节，另附原始叠加定义。

## 文件与编辑范围

[作者原始 PDF](original.pdf) · [SVG 转换件](source.svg) · [原始 LaTeX 插图定义](figure-inclusion.tex) · [来源与校验记录](metadata.json)

作者独立 PDF 中的文字与图形对象保留；SVG 文字转为轮廓。这张独立原图未检出嵌入位图。

原作者把章节或引文编号放在 LaTeX 中叠加，独立 PDF 与转换 SVG 保留其编号空槽；配套 figure-inclusion.tex 是原始叠加定义。

原始 PDF 来自作者提交的 TeX 归档，未改字节；SVG 是格式转换件，未取得原生 AI 工程。桌面 Illustrator 尚未逐项实测。
