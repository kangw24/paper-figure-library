# 内容建模与科学机制复审

## 从纲要得到值得成图的问题

不要把每一级标题变成一个框。寻找需要视觉解释的关系：同一问题的多种表述、实例与函数族、约束进入算法的位置、困难产生的机制、不同数值对象的对照。

一幅图先确定主张，再列支撑子图；每个子图回答“增加了什么可观察关系”。只有方法名清单时可能更适合表格，只有一句背景结论时不必强造复杂 teaser。

本案例六图的角色为 01 学习对象、02 设计选择、03 数学表述、04 实例拟合与算子学习、05 不同困难与机制、08 物理约束进入位置。科学语言一致不要求版式一致。

## 每个显示对象有明确身份

| 身份 | 可以表达 | 不可暗示 |
|---|---|---|
| 符号架构/特征 | 维度、作用、输入输出 | 已学得权重或实际精度 |
| 解析例子 | 该例子的性质与机制 | 普遍实验表现 |
| 数值参考解 | 已说明离散与求解器下的参考 | 神经预测、无条件真值 |
| 合成观测 | 参考过程产生的采样值 | 实验实测、独立真实性证据 |
| 固定试探状态 | 当前残差与诊断 | 训练后改善、收敛过程 |
| 实际训练输出 | 有记录实验的预测 | 超出评测条件的泛化保证 |

图内用必要的短标签避免误读；完整参数、求解设置与局限放图外题注或复现文件。不能以“不要小字”为由删去科学身份，也不能把所有元数据塞入图内。

## 审查每条箭头

区分数据流、参数更新、构造依赖、局部展开、对应比较。分别写出起点、终点、传递的量或操作。

常见错误：把训练对 `(a,u)` 整体接入只接受 `a` 的模型；把目标 `u` 画成前向输入；把 DeepONet 与 FNO 两种实现串联；把更新回线接到坐标而非参数；把局部放大引线画成演化过程。

## 四层科学审查

1. **对象与维度**：域、坐标、时间、空间/频率/通道索引、输入输出形状。
2. **方程与条件**：算子、符号、单位、源项、初边值条件、函数空间和正则性。
3. **连续与离散**：连续等价是否偷换为任意离散等价；采样平均、求积和概率权重是否混淆。
4. **证据与措辞**：软惩罚是否变成硬保证；参考图是否冒充模型结果；未训练是否出现收敛曲线。

核算具体表达，不能用术语完整代替验证。新科学主张查原论文、官方文档或可靠教材；下面是本项目检查案例，不是普适方法分类。

## 六图中可复用的检查例

### 01：学习对象与实例条件

参数识别、动力学学习、坐标解拟合、解算子学习的输入输出不同。逆问题的可识别性与观测覆盖不能省略。用于说明算子变化的场来自不同输入条件，不是同一解换几种着色。解析轨迹只作为参考示例。

### 02：表示、方程、目标与离散是不同选择

有限基和神经表示都可能导向代数求解或优化；不能画成“传统方法只能解方程、神经方法只能最小化损失”。

残差双范数 `rᵀG⁻¹r` 中，`G` 来自选定测试内积与有限线性无关基，求逆要求相应非退化条件。能量最小化要求适当变分结构，不是所有 PDE 的替代形式。

求积点使用真实规则；随机点不是三角形高斯求积。控制体面法向、通量方向与源项符号必须采用同一约定。

### 03：同一 Poisson 问题的多种表述

案例为单位圆盘 `−Δu=1`、零 Dirichlet，参考解 `(1−r²)/4`。扰动 `0.1(1−r²)x` 产生强残差 `0.8x`（残差定义为 `−Δu−1`）。试探族 `c(1−r²)` 的能量为 `πc²−πc/2`，最小点 `c=1/4`。

这些关系可直接核算，用来检查各子图是否同一问题。弱测试函数须符合空间条件；有源 Poisson 的边界积分表达不能丢体源项。连续表述间的联系不保证任意离散、求积和优化都等价。

### 04：函数族、模型输入与算子实现

同一椭圆问题比较固定实例与系数到解映射，保持源项和边界一致。输入系数、有限差分参考解、符号模型输出分别标身份。数据目标只进入比较，物理项使用匹配系数与输出。

DeepONet：固定传感值进入 branch，查询坐标进入 trunk；等长特征做内积。不要把二维场突然换成无说明的一维曲线。

FNO：保留谱路径、逐点路径和激活；频率位置与特征通道分清。谱权重在同一频率混合通道，不能画成任意频率互连。居中频谱需说明 shift。

离散表示条带比较采样、离散映射和输出重构；不能添加未经验证的相等号、精度勾号或“任意分辨率保证”。固定传感器输入与输出查询的灵活性不是同一概念。

### 05：四种困难不能统称不连续

- 解跳跃、角点导数奇异、点源/奇异核、光滑薄层是不同机制。
- Burgers 激波需要弱守恒及熵可容许条件；`uL=1,uR=0` 时激波速度为 `1/2`。
- 凹角局部奇异模态加截断富集会改变余项方程和边界，不能漏掉截断函数导数的乘积项。
- 点源解与积分核奇异性分开；强奇异核可能需要特定正则化，不能一律普通求积。
- `exp(−x/ε)` 的边界层是光滑的；缩放坐标和细网格用来解析尺度。放大图显示同一网格局部，不临时重画另一套。

不是所有点源解都属于通常的 `H¹` 能量空间；加上 weak form 标签不会自动消除正则性问题。

### 08：构造、采样和诊断来自同一状态

案例为有孔方域上的零边界 Poisson 问题。边界消失因子 `d=(1−x²)(1−y²)(x²+y²−r₀²)` 在内外边界为零，但不是精确距离函数。基线也满足边界时，`u_base+dNθ` 才有相应硬边界性质。

显示的是一模态 Ritz 基线和固定四 RBF 修正状态 `θ₀`；观测来自更高阶 Ritz 参考。不能称为训练后结果。

原配点按基线残差权重一次无放回选取；在这些点计算当前场残差，不等于当前场驱动的迭代自适应。初始抽样权重、最终入选概率、积分权重不同。

`j=−∇u` 时，净向外通量减体源等于控制体内 PDE 残差积分，是同一方程的检查，不是独立新物理。反射一致性依赖域、源、边界对称性及相应唯一性。有限采样软损失不保证全域精确对称。

观测误差可用参考值—试探值配对图，不编造样本序号趋势。观测数、配点数属于复现信息；若不构成比较结果，不做成醒目装饰数字。

## 复审输出

按“图/子图 → 具体对象 → 严重性 → 依据/核算 → 改法”报告。区分已证明错误、潜在误读、待查来源。先消除科学错误，再调美术。

建立问题到主题的映射：原研究范围如何保留、移位或增加条件。不能以“科学安全”为由静默删到只剩几个简单模块。
