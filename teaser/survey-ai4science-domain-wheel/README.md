## 为什么收这张图

用三层圆环把量子、原子与连续系统统一起来：外圈是研究对象的视觉实例，中圈是学科和任务，中心是对称性、泛化与不确定性等共同议题。领域覆盖与核心观点同时可见。

综述概念总览，原文 Figure 1；适合借鉴中心观点与周围领域互相支撑的 teaser 构图。

## 可以借鉴

- 中心放跨领域的共同问题，环形分区放具体研究方向，避免只做装饰性圆环。
- 用分子、蛋白、材料和流体等真实对象作为外侧视觉锚点。
- 大类、小类和共同议题分别使用不同空间层级，保留作者对本综述范围的限定。
