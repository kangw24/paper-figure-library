## 为什么收这张图

把 VideoGen、OccGen、LiDARGen 画成三组有主干和侧枝的研究地图，在分支处标出数据引擎、动作解释、场景表征和预测等功能，兼顾密集代表工作与整体方向。

综述代表方法的分类地图，原文 Figure 2；分枝表达功能归类，不表示模型之间真实的技术继承。

## 可以借鉴

- 用主干区分大范式、侧枝区分功能，把视觉拓扑和分类语义绑定。
- 模型标识与名称保持小而统一，方向名称在分枝末端放大。
- 角落的年度统计与主要分类地图分离；所列方法和统计是对应版本的历史快照。
